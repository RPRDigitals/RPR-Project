# RPR Digitals + RPR Gent's Hostel

## Pages
- `index.html` — RPR Digitals agency landing page.
- `hostel.html` — dedicated RPR Gent's Hostel landing page.

## Assets
- `assets/rpr-digitals-logo.png` — uploaded brand logo.

## Run locally
Open `index.html` directly, or use VS Code + Live Server.

## Before publishing
1. Replace the WhatsApp `https://wa.me/` placeholders with the real WhatsApp number.
2. Replace the hostel gallery placeholders with actual hostel photos.
3. Verify the current room pricing and address.
4. Update the Google Maps search link with the exact hostel location.
